# Materials per a la convocatòria 4D

**Preparats, no presentats.** Aquesta carpeta conté el text de la candidatura
d'Identitat.digital a la convocatòria de <https://4d.cat/convocatoria/>. Cap
formulari no s'ha enviat i cap document no s'ha tramès a l'organització.

| Fitxer | Què és |
| --- | --- |
| `descripcio.md` | La descripció del projecte: objectius, complexitat tècnica i problemes que vol resoldre. Pensada per ocupar dues pàgines. |
| `calendari.md` | Calendari amb lliurables tangibles i data de comprovació de cadascun. |
| `respostes-curtes.md` | Llicències, finançament, equip i enllaç al currículum, en el format de resposta breu que demana el formulari. |
| `pressupost.md` | Desglossament de l'import sol·licitat i què passa si se n'atorga menys. |

## Dades de la convocatòria que condicionen el material

| | |
| --- | --- |
| Import | De 5.000 a 10.000 € |
| Pagament | 90 % a la presentació, 10 % en acabar |
| Presentació | 29 d'octubre de 2026, a Barcelona, **presencial i obligatòria** |
| Termini de sol·licitud | 25 de setembre de 2026 |
| Qui s'hi pot presentar | Entitats europees |
| Criteri destacat | Es prioritzen les llicències lliures |

## Abans d'enviar res

1. Rellegir el text de la convocatòria vigent el dia de l'enviament. Aquests
   materials es van escriure el 12 de setembre de 2026 i les bases es poden
   haver modificat.
2. Comprovar que les xifres de l'apartat «Estat actual» del `README.md` del
   repositori i les que apareixen a `descripcio.md` coincideixen. Si el corpus
   ha crescut, les del formulari han de ser les del dia.
3. Confirmar la disponibilitat real per ser a Barcelona el 29 d'octubre de
   2026. Sense aquesta assistència no hi ha ni el 90 % ni el 10 %.
4. Adjuntar l'enllaç al repositori públic, que és l'única part de la
   candidatura que el jurat pot verificar sense creure's res.
